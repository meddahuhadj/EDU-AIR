How it works

A classroom that answers to you

There is no magic: hand tracking and voice recognition run on the classroom PC itself. The projector never uploads anything.

1

See you

A standard webcam points at the teacher. Fingertip and hand pose are tracked locally with MediaPipe — mirror-corrected and spike-filtered.

2

Understand you

Gestures and spoken commands (next slide, start quiz, answer B…) become classroom intents. Everything you didn't ask for is refused by a safety gate.

3

Project for you

The projector becomes the board: a steady on-air pointer, slide control, ink and highlights at distance, and a live scoreboard quiz — all rendered as an overlay.

Features

Everything a teacher needs, at a distance

Built on the HADJ NO-TOUCH AI engine and re-focused for the classroom, with a deny-by-default safety gate on every action.

On-air pointer

Calibrated fingertip pointer with dead zone, spike rejection and EMA smoothing. Three sensitivity presets (low / medium / high) and tremor metrics on the HUD.

Slide control

Drive PowerPoint, Impress or PDF: F5 start, arrows, B black/pause, Ctrl± zoom, PgUp/PgDn scroll. Every command writes an audit record.

Air annotation

Draw, highlight, dot and erase ink on the projected image — point, stroke, wide translucent glow. Normalized coordinates look identical on any projector. Undo included.

Live voice quiz

Voice-driven QCM: start/end, next question, show answer, answer A–D (b, ب …). Scoreboard with correct/wrong/skipped and per-question timing.

Classroom timer

Start, stop and reset a class clock by voice — visible in the overlay HUD next to the tools.

5-step calibration

Camera → projection area → corners → alignment → gesture test. Builds a webcam→projector homography (RANSAC, affine fallback). Skipped corners are honestly flagged as estimated.

Accessibility first

Large targets, dwell-click presets, one-hand gestures, reduced-motion mode and voice-first hinting — so every teacher can keep working at their own pace.

Voice-first

When your hands are busy (gloves, tools, holding papers) voice becomes the main channel — same intent engine, same safety gate.

Safety

Deny by default, refuse nothing important

Every action goes through a classroom safety gate and an audit trail. Unknown actions are refused — a typo or a future AI command can never trigger an arbitrary action.

Registry-gated

Only registered classroom actions exist. Anything unlisted is denied and audited as blocked.

Graded risk

Next slide, zoom, timer, quiz start run instantly. Clearing all annotations asks first. Ending the quiz is critical and is never auto-approved.

Always reachable

Pause, pointer off and the stop toggle never get blocked by a prompt — an incident can always be stopped reflexively.

Honest demo

Demo mode runs the same state machine with synthetic hands and a scripted lesson; it auto-approves to stay fluid and touches nothing on your real system.

Privacy

Your classroom stays in the room

Camera processing is local by default — no camera frames are uploaded or recorded. The voice engine is the only choice: it is always visible, never silently switched.

Frames stay local

MediaPipe + OpenCV run on the classroom PC. Zero uploads, zero cloud for gestures.

Voice is a choice

Google's online engine sends the spoken phrase to Google — flagged AUDIO ONLINE. Vosk or SAPI keep recognition 100% local (AUDIO LOCAL). If a local engine can't run, voice disables instead of silently falling back.

No account

No login, no telemetry, no updates being pushed during a lesson. Settings are a JSON file in the user folder.

Auditable

Every executed, blocked or pending action is written to the rotation log and the in-memory audit trail.

FAQ

Questions teachers actually ask

Do I need a touchscreen?

No. A computer, a webcam and a projector are enough. The air pointer and ink work at a distance — there is no touch frame and no sensor.

Which slide software does it drive?

PowerPoint, LibreOffice Impress and PDF readers, through standard keys (F5, arrows, B, Ctrl±, PgUp/PgDn). It drives the presentation, it doesn't replace it.

Which languages?

The interface and voice commands work in English, French, Arabic and Dutch — independently. Teach with an Arabic voice and an English interface if you like.

Does it need internet?

No. Hand tracking and the demo run offline. Voice uses Google's cloud by default; choose Vosk or SAPI to make recognition fully offline. If an offline engine can't start, voice turns off rather than silently going online.

Is it free?

Free, no account, no telemetry. A portable ZIP for Windows 10/11; install nothing if you just want the landing page and this demo.

Is calibration optional?

You can skip it, but it stays honest: skipped corners are flagged as estimated, never silently precise. Re-run the 5-step wizard any time from the dock.
